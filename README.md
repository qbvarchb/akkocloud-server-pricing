## 伦敦这台 ¥33000/月，配置对应什么业务

**双路 EPYC 7552**。这是服务器级平台，两颗物理 CPU 直接装在这台机器上，核心数不是 VPS 那种从宿主机切出来的份额能比的。长期满载的编译、视频转码、批量数据处理、跑多个业务容器，这类吃持续算力的活儿才用得上这种规格。

**512G DDR4**。内存是独立服务器和 VPS 最直白的差距。官网首页那两款 VPS 是 512MB 和 768MB 内存，512G 相当于后者的六百多倍。大型关系型数据库、内存缓存集群、把整份数据集常驻内存做查询，是这个容量真正的用途。

**10×1TB SSD**，合计 10TB 原始容量。多盘位意味着可以自己做 RAID 做冗余，也可以把系统和数据分开放在不同盘上。具体能不能指定 RAID 级别、阵列卡什么型号，官网没写，属于询价时要问的内容。

**500Mbps CN2 GIA 带宽**。官网对海外服务器的原话是“与中国电信的下一代运营商网络（CN2）网络连接”，独立服务器板块的表述是“采用高性能 CPU、NVME 固态硬盘并提供高速 BGP 网络”。这里有一处需要留意：宣传语写的是 NVMe，伦敦这台的配置单写的是 10×1TB SSD，没写 NVMe。下单前把硬盘的具体类型和接口问清楚，尤其是你打算跑高 IOPS 的数据库。

价格换算一下：按月付计算，一年是 ¥396,000。官网没有说明长付周期有没有折扣，别自己假设年付会便宜。

## 三个没有公开报价的机房，询价时问什么

圣何塞、法兰克福、香港三地的独立服务器在官网上只有分类入口，没有配置单和价格。圣何塞离国内最近，适合对延迟敏感的业务；法兰克福面向欧洲用户；香港则是亚太业务和国内访问兼顾的选择。这三个机房具体给什么硬件、什么价，只能问。

提交工单时把需求写具体，来回次数能少很多：

- 用途和预估负载（数据库、站点集群、转码、代理中转）
- 需要的 CPU 核心数、内存容量、硬盘容量与类型
- 带宽大小、月流量是否封顶、超流量怎么计费
- 需要几个 IP、能否增加、是否保证原生
- 操作系统与虚拟化方式（物理机是否支持自定义 ISO）
- 交付时间、是否有 Setup 费、付款周期与续费价

问完拿到报价，再和伦敦这台公开价对比，判断溢价是否合理。
